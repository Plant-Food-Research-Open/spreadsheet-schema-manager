SSM is built with [Rio](https://rio.dev/), a Python web framework: the UI and backend logic
are both Python, in `spreadsheet_schema_manager_rio/`.

Contributions are welcome. If you're planning a change, open an issue or discussion first so
the approach and scope are clear. When you change the app's behaviour, configuration or
deployment, update these docs in the same pull request. See
[CONTRIBUTING.md](https://github.com/Plant-Food-Research-Open/spreadsheet-schema-manager/blob/main/CONTRIBUTING.md).
