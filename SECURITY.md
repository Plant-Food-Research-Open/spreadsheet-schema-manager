# Security Policy

## Supported Versions

The project currently supports the latest version on the main branch. Security fixes are prioritized for the current development and deployment versions in use.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, please do not open a public issue.

Please report it privately by contacting the project maintainers through the repository's preferred reporting route, such as the GitHub security advisory flow if enabled, or a direct maintainers contact.

Please include:

- a description of the issue
- steps to reproduce the problem if possible
- the affected version or commit hash
- any relevant logs, screenshots, or proof-of-concept material

We will acknowledge receipt as quickly as possible and work with you on a coordinated fix and disclosure plan.

## Disclosure Policy

We aim to:

- confirm the report and assess impact promptly
- provide a fix or mitigation plan as soon as feasible
- disclose the issue responsibly once a patch is available or after a coordinated release

## Responsible Disclosure

We appreciate responsible disclosure and ask that reports be kept confidential until a fix is ready. This helps protect users and avoids unnecessary exposure of vulnerabilities in the wild.
