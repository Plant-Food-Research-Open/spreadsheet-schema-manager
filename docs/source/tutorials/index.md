# Tutorials

Three tutorials, from simplest to most advanced. They all follow the same apple-assessment
trial, so do them in order.

| Tutorial | You'll learn to | Time |
| --- | --- | --- |
| [Your first Workbook](first-workbook.md) | Define Fields and download a ready-to-fill Excel Workbook | 10 minutes |
| [Reuse a setup with Templates](templates.md) | Reuse a Workbook's setup, pick up changes to Fields, record constant values and print labels | 10 minutes |
| [From legacy spreadsheets to a shared schema](legacy/index.md) | Bring existing spreadsheets into one shared schema (advanced) | 45 minutes |

Each tutorial is written for your personal space. If a team is your active team, clear it in
[Settings](../getting-started/settings.md) first, so you don't change the team's Fields.
